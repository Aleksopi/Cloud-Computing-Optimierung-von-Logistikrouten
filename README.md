# Projekt 9: Optimierung von Logistikrouten

## Ziel

In diesem Projekt werden Sie lernen, wie man Transportrouten optimiert, um Kosten, Zeit und Umweltauswirkungen zu reduzieren.

Sie werden Graphenalgorithmen anwenden, um die effizientesten Wege zwischen verschiedenen Standorten zu finden, unter Berücksichtigung von Faktoren wie:

- Entfernung
- Verkehr
- Transportkapazität

Logistikoptimierung ist für Unternehmen mit Lieferketten von entscheidender Bedeutung und kann erhebliche Einsparungen sowie Umweltvorteile bringen.

---

## Tools

### Neo4j
Eine Graphdatenbank, die für die Speicherung und Abfrage von vernetzten Daten optimiert ist.

### Google OR-Tools
Eine Suite von Optimierungstools, die Algorithmen für Routing-Probleme enthält.

### Folium
Eine Python-Bibliothek zur Visualisierung von Geodaten auf interaktiven Karten.

---

## Datensätze

### OpenStreetMap-Daten
Enthalten Straßennetze, Gebäude und andere geografische Informationen.

### Optional
Verkehrsdaten oder Wetterdaten, die die Routenplanung beeinflussen können.
